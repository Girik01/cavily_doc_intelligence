# What to load for the demo (Cavli C16QS)

The system starts empty. For the demonstration, give it these sources on the **Sources** tab. Nothing is built into the code.

## 1. Links (paste into the "Links" box, one per line)
```
https://www.cavliwireless.com/iot-modules/c-series/c16qs
https://d8wojkg2185gh.cloudfront.net/strapi/C16_QS_Declaration_of_Conformity_cb491e43d4.pdf
https://www.cavliwireless.com/iot-modules/lte-Cat1-bis-iot-module
https://www.cavliwireless.com/faq/c-series-faq
```
Optional (more Cavli pages that also work): the three C16QS blog posts
```
https://www.cavliwireless.com/blog/product-feature/secure-smart-metering-with-cavli-c16qs
https://www.cavliwireless.com/blog/product-feature/cavli-c16qs-iot-modules-wifi-scanning-enhanced-connectivity
https://www.cavliwireless.com/blog/product-feature/dual-form-factor-evolution-of-cavli-c16qs-module
```

## 2. PDF files (two versions of the same document)
Cavli's own site does not publish the technical specification. Two public third-party distributor copies exist; download them and keep the names below
(a trailing version and "(2)" are removed from the document title, the version name is typed by you).

| File to save as | Download from | Version name to type |
|---|---|---|
| `C16QS Technical Specification Document V2.0.pdf` | https://mc-technologies.com/wp-content/uploads/2024/01/C16QS-Technical-Specification-Document-V2.0.pdf | `V2.0` |
| `C16QS Technical Specification Document V2.9.pdf` | `https://www.endrich.com/Datenbl%C3%A4tter/Filter%2C%20Quarze%2C%20Antennen%2C%20Funkmodule%2C%20NFC%2C%20WPC/Cellular/C16QS%20Technical%20Specification%20Document%20V2.9%20%282%29.pdf` | `V2.9` |

The PDFs do not state a version themselves; the labels V2.0 and V2.9 come from the file names and are typed by the uploader. The app never guesses a version.

## 3. Documents that exist but are not accessible (optional box on the Sources tab)
```
Product brochure | released only through a web form
Hardware manual | needs a login on the Cavli customer portal
AT command manual | needs a login on the Cavli customer portal
```

## Order for the demo
1. Process the links (box 1), then the V2.0 file with the version name `V2.0` (the "before" state).
2. Ask a question in the chat, for example "What is the sleep mode current?" (V2.0 says TBD).
3. Under the document list, "Add a newer version of a document": choose the technical specification, choose the V2.9 file, version name `V2.9`, upload.
4. Ask the same question again (V2.9 says 11 µA). Look at "What changed" and at Expert review.
5. Evaluation tab: generate and run.
